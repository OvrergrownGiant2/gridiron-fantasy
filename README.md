# Gridiron Fantasy — setting up

You've uploaded the setup files. The first run of **Actions → Publish app** unpacks the full
source into this repository, downloads the latest real NFL data and publishes the website at
`https://<your-username>.github.io/<repo-name>/`. It takes about 3 minutes.

If the run shows a red ❌ saying GitHub Pages is not switched on: open **Settings → Pages**,
set **Source** to **GitHub Actions**, then **Actions → Publish app → Re-run all jobs**.
